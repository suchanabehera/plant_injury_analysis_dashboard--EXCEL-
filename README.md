# Plant Injury Analysis Dashboard (Excel)

## Project Overview

I am excited to share my first excel project cum academic case study which i have completed by my own as part of my Data analytics program.

This project analyzes workplace injury data across multiple manufacturing plants using Microsoft Excel. The dashboard helps identify injury trends, affected plants, departments, shifts, age groups, and overall incident costs. The objective is to support management in making data-driven safety decisions.

## Objectives

- Analyze total workplace incidents.
- Identify the most affected plant and department.
- Track yearly incident trends.
- Compare incidents across shifts.
- Analyze incidents by age group, gender, body part, and report type.
- Calculate total incident cost and total days lost.

## Tools Used

- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Dashboard Design & Formatting

- Most Affected Department

## Visualizations

- Incident Cost by Plant
- Year-wise Incident Trend
- Incident Type by Shift
- Gender-wise Incidents
- Incident by Department
- Report Type Distribution
- Incidents by Age Group
- Injuries by Body Part

### Interactive Filters
 - Year Slicer
 - Plant Slicer
 - Shift Slicer

## Key Insights
- Kolkata recorded the highest number of incidents.
- Shipping was the most affected department in Three Years
- Male employees are majorly affected by incidents than females
- Employees aged 46–60 experienced the highest number of incidents.
